## Design decisions the block left unstated

1. **`credentials: "include"` removed from `apiRequest` and `getQueryFn`.** *Flagged — beyond
   D.4's text.* `app.ts:45–51` configures `cors({ origin, allowedHeaders })` with no
   `credentials: true`, and the live preflight below returns no
   `access-control-allow-credentials`. A cross-origin request in credentials mode `include`
   fails the CORS check without that header, so once D.4 gave these two the API base they
   would have failed on every response in production — a new latent defect in place of the
   old one. The API reads no cookie: the only cookie reference in `api-server/src` is a
   log-redaction path (`lib/logger.ts:9–10`). Neither function has a caller today (every
   `useQuery` supplies its own `queryFn`; `apiRequest` is called nowhere), so no current
   request changes. Two lines to reverse.
2. **The `/api/` runtime check also sits inside `sessionFetch`**, not only in `getQueryFn`.
   The type stops everything except a value typed `any` or cast (F-d); the check makes those
   throw `ApiPathError` instead of fetching `API_BASE + "https://…"`. `sessionFetch` became
   `async`, so the throw reaches callers as a rejection, like every other failure they
   already handle.
3. **`apiRequest` is typed `ApiPath`** — statically `/api/…`, so D.4's runtime clause applies
   only to `getQueryFn`. Kept although it has no caller, because D.4 names it.
4. **`latestId` / `setLatestId` removed from `Home.tsx`** — declared, never set, never read;
   left over from the design this block replaces.
5. **T1 uses two locations** (Fuengirola, then Almería), and the mock records `{ id, location }`
   per insert, so "the id storage returned for that call" is pinned by location as well as by
   order.
6. **`{ ...result, id: saved.id }`** — the insert's id is written last, so it wins over any
   `id` key `result` might ever grow.
7. **`@workspace/api-client-react` not touched.** It is a declared dependency of the web
   package with its own `setBaseUrl` (`lib/api-client-react/src/custom-fetch.ts:28`), but no
   web source file imports it, so it is not a place the web's API base is applied. Out of
   fence.
