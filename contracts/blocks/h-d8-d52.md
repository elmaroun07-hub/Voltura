## Named failure modes

- **F-a** Balancing the table by shrinking "Generated". Generated is what the panels produced and must not change.
- **F-b** Calling the surplus "exported", or giving it a value. Nothing is sold; saying so is a new claim.
- **F-c** Old rows showing 0% battery or 0 surplus because a field is absent. That is the `?? 0` family this repo keeps fixing (D6).
- **F-d** The money moving. If any money figure changes on any fixture, dispatch changed. Stop and find out why.
- **F-e** Recomputing the donut algebraically again (usage minus grid minus solar). Every slice must be a recorded sum.
- **F-f** Hiding the chart instead of measuring it. Only via §STOP and an operator ruling.
- **F-g** Presenting the mix as the household's measured data. It rides the synthetic hourly profile. Add no wording that claims more than "modelled".
