# Code of conduct

Voltura is about housing and the people who live in it. Treat the people in this project the same way.

## Expected

- Be respectful, including when you disagree.
- Criticise code and claims, not people.
- Back factual claims with a source, the same rule the code follows.

## Not accepted

- Harassment, insults or personal attacks.
- Discrimination on any ground, including origin, religion, gender, sexuality, disability or age.
- Publishing anyone's private information, including data about a specific household or address.

## Reporting

Email elmaroun07@gmail.com with `[Voltura conduct]` in the subject line. Reports are kept private.

The maintainer may edit or remove comments, issues and pull requests that break these rules, and may block people who repeatedly do.
