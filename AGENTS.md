## How to work in this repo
- Read a file before changing it. Re-read it only if it changed.
- Think it through fully, but keep replies short.
- Leave files over 100 KB alone unless the task needs them.
- No flattering openings or filler closings.
- No emojis, no em-dashes.
- Never state an API, version, flag, commit SHA or package name from memory. Confirm it in the code or docs first.
